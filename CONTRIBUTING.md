# Contribuer

Merci de votre intérêt pour les modules Lectura.

- **Rapports de bogues et suggestions : bienvenus.** Ouvrez un ticket (issue) en décrivant le module, sa version, l'entrée utilisée, le résultat obtenu et le résultat attendu.
- **Contributions de code : non acceptées.** Les modules sont distribués sous double licence (AGPL-3.0-or-later, ou licence commerciale). Pour préserver cette double licence, Lectura reste seule autrice du code : les demandes de fusion (pull requests) ne seront pas intégrées. Une correction proposée dans un ticket peut être reprise et réécrite par Lectura.

---

**Contributing.** Bug reports and suggestions are welcome: please open an issue. Code contributions (pull requests) are not accepted, in order to preserve the dual licensing (AGPL-3.0-or-later or commercial licence).
